# Scale Benchmark Baseline - 2026-06-06

This baseline records the first Scale benchmark run that motivated the safe-composition roadmap. It is historical evidence. The live benchmark contract is `cases.json`.

## Questions Tested

1. How big is Seattle's operating budget?
2. How big is King County's budget?
3. How have both changed over 5-10 years?
4. What is the per-resident budget for each?

## Evidence Details

### Seattle Current Total

Plugin-supported result:

```text
FY2026 approved operating budget = $7,311,905,121.57
Rows = 7,622
Source = City of Seattle Operating Budget, Socrata ID 8u2j-imqx
Measure = sum(approved_amount)
Filter = fiscal_year = 2026
```

Reproduction:

```bash
curl -sS --get 'https://data.seattle.gov/resource/8u2j-imqx.json' \
  --data-urlencode '$select=fiscal_year,sum(approved_amount) as total,count(*) as rows' \
  --data-urlencode '$where=fiscal_year=2026' \
  --data-urlencode '$group=fiscal_year'
```

Important caveat:

```text

The plugin's checked-in dashboard source reports annual dashboard budgeted values.
These should be reconciled or presented side by side, not treated as identical.
```

### Per-Resident Scale

Strict plugin-only result:

```text
Unsupported. Current Seattle and King County budget source cards do not include official population denominator sources.
```

External OFM population used for audit calculation:

```text
Seattle April 1, 2025 population = 816,600
King County April 1, 2025 population = 2,411,700
```

Audit calculation:

```text
Seattle FY2026 operating budget per resident ~= $8,954
King County FY2026 dashboard budgeted expenditure per resident ~= $3,565
```

This should become a benchmark that expects the plugin either to use an accepted population source or to clearly say which denominator source is missing.
