# Pierce County, Washington

Second-largest Washington county (~959,900 residents, OFM April 1, 2025). Both accepted sources are live-tier Socrata datasets on the county's official open data portal - the same access pattern as Seattle, with no checked-in snapshots.

- `skill.md`: jurisdiction analyst skill (routing target).
- `sources/open-budget.source.json`: biennial budgeted expenditure with budget-line-grain actuals, 2016-2017 through 2026-2027.
- `sources/open-checkbook.source.json`: transaction-level actual spending, fiscal years 2017 through the partial current year.
- `data/README.md`: live tier - no snapshot artifacts.

Probe brief: `docs/source-probes/pierce-county-open-data.md`.
